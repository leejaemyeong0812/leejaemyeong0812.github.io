01-youtube 개인정보처리방침

시행일: 2026년 10월 27일

1. 이 도구가 하는 일

01-youtube는 운영자 본인의 YouTube 채널에 영상을 올리는 개인용 도구입니다. 운영자 본인만 자신의 Google 계정으로 로그인해 사용합니다. 이 도구는 YouTube API 서비스(YouTube API Services)를 사용합니다.

2. 접근하는 정보와 사용 목적

  • YouTube: 운영자 본인 채널에 영상·쇼츠 업로드, 썸네일·자막 등록, 공개 설정(예약 공개 포함)
  • Google 드라이브: 이 도구가 만든 놀이 카드 PDF 파일만 올리고 공유 링크를 만듭니다(drive.file 권한). 드라이브의 다른 파일은 읽지 않습니다.

시청자나 다른 사용자의 개인정보는 수집하지 않습니다.

3. 보관

로그인 결과로 받은 인증 토큰은 운영자 본인의 컴퓨터에만 파일로 저장되며 외부 서버로 보내지 않습니다. 업로드 기록(영상 ID, 업로드 시각)도 운영자 본인의 컴퓨터에만 저장됩니다.

4. 제3자 제공

이 도구는 어떤 정보도 제3자에게 판매하거나 제공하지 않습니다. 업로드한 영상과 파일은 YouTube와 Google 드라이브에 저장되며, 그 처리는 각 서비스의 정책을 따릅니다.

5. 관련 약관

  • YouTube 서비스 약관
  • Google 개인정보처리방침

6. 접근 권한 철회

Google 계정의 서드파티 액세스 관리 페이지에서 언제든 이 도구의 접근 권한을 해제할 수 있습니다. 운영자 컴퓨터의 토큰 파일을 지우면 저장된 인증 정보도 삭제됩니다.
